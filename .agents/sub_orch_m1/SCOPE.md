# Scope: Milestone 1 — Foundations, Arrays, Linked Lists & Stacks/Queues (Modules 01-04)

## Architecture
- Module directories: `src/module01_foundations`, `src/module02_arrays_and_strings`, `src/module03_linked_lists`, `src/module04_stacks_and_queues`.
- Standalone `.java` micro-step files (`Step01_...` to `Step06_...`).
- Package declarations: `package moduleXX_name;`
- Self-contained: includes static inner classes and `public static void main(String[] args)`.
- Includes rich inline ASCII diagrams for stack/heap memory, pointer manipulation, sliding window bounds, circular queue wrap-around, and call stack recursion.
